1 Release notes
1.1 Features in 1.6.5
1.1.1 New Panel Analysis
Panel analysis page is now a single view for every equipment of each line.
Images of defects is displayed in the same screen main screen.
The indicators for each equipment are stored in tabs for each of them. They contain the same
information as before:
- Summary counters and view
- Errors, Warnings, Measures tables
- Measure charts
Limitation on analysis of glue deposit defects, localization and correlation are not supported
when component are not defined.

2 Installation
2.1 Requirement
 Microsoft Windows 7 minimum
 Java 7 minimum
2.2 Prepare installation
Preparation is same for the SigmaLink server or inline review.
Administrator rights on the computer are necessary to perform the installation.
Download a Java Virtual Machine (JVM).
Windows 32 bits or Windows 64 bits
If you prefer you can download directly on Oracle web site
Download the installer
http://sigmalink.vitechnology.com/deliver/download/analyse/1.6.3/installer/windows_32
http://sigmalink.vitechnology.com/deliver/download/analyse/1.6.3/installer/windows_64
2.3 Installation
Administrator rights on the computer are necessary to perform the installation.
Launch the downloaded binary by double clicking on the file installer.jar.
In some cases, double-click doesn’t work. Then use a command line and launch java –jar
installer.jar in the directory of the downloaded file.
