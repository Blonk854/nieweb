Sigmalink 1.6.5 Release and installation notes
2.1 Prerequisite
2.1.1 Define which module to install and where
SigmaLink is composed of three different software.
• SigmaLink server: used to manage data import, offline review, repair station and remote
review. This software must be installed once by factory, ideally on dedicated server. The
machine must be visible on the network from inspection machines and programming desktop.
• Inline review server. Must be installed on a dedicated computer in each line.
• Analysis server: provide analysis functionality without disturbing production tools like review
and data import.
2.1.2 Compatibility
Sigmalink can communicate with specific SQL Database server version:
- Microsoft SQL Server 2008 R2 or higher
Sigmalink client running Data Import module needs to work with specific version of Java :
- Java version 7.71 maximum
- Java version 7.51 minimum
2.2 Prepare installation
Preparation is same for the SigmaLink server or inline review.
Administrator rights on the computer are necessary to perform the installation.
Download a Java Installer 8 from Sigmalink deliver website.
http://sigmalink.vitechnology.com/deliver/download/public/java/8/windows_32

http://SigmaLink.vitechnology.com/deliver/download/1.6.5/installer/32 or
http://SigmaLink.vitechnology.com/deliver/download/1.6.5/installer/64
Download a license file (contact your reseller).
Install the Java Virtual Machine.
Launch the downloaded binary.

If you have install Link with the bad installer: 32 bits instead or 64 bits, you’ll have the
message “Can't load IA 32-bit .dll on a AMD 64-bit platform”. Use Ctrl+C to close the DOS
Console, delete the directory C:\VIT_SigmaLink, download the good installer and redo the
installation.
If you got the message “Could not reserve enough space for object heap”, SigmaLink was not
able to detect memory quantity. You’ll have to edit the file start_server.bat to update the
variable MAX_HEAP_SIZE (for 64bits system) or MAX_HEAP_SIZE_32 (for 32bits system). E.g.
replace the line SET MAX_HEAP_SIZE_32=1536 by SET MAX_HEAP_SIZE=1024 to allocate 1GO RAM.
When the server is started, you can find a log like “INFO: Starting ProtocolHandler ["http-nio-
XXXX"]”. XXXX is the port to use in URL to connect to the server.
2.7.2 Stopping server
Use Ctrl+C in the DOS window and wait until server is stopped, then close the window.

2.7.3 Installation as scheduled task
You can find 2 scripts in the directory named ‘tools’:
Install_http_service.bat to install SigmaLink as windows service.
Uninstall_http_service.bat to uninstall SigmaLink as windows service.
Launch VIT Sigmalink Server (service) into the windows services screen.
After this installation, if you can’t contact the SigmaLink Server. You need to add tomcat7.exe
and tomact7w.exe to the Windows Exception List.
To do that:
1. Windows Start Menu ➔ Launch control panel
2. Security and System
3. Select Firewall Windows
4. Click "Allow a program or feature through windows firewall"
5. Modify the parameters/”Allow another program…”
6. Browse on your desktop pc and select :
C:\VIT_SigmaLink\server\apache-tomcat-7.0.55\bin\tomcat7.exe
C:\VIT_SigmaLink\server\apache-tomcat-7.0.55\bin\tomcat7w.exe
7. Check the checkbox before and after Commons Daemon Service Runner
2.7.4 Installation as scheduled task
You can find 2 scripts in the directory named ‘tools’:
install_http_scheduled_task.bat to install SigmaLink as scheduled task.
uninstall_http_scheduled_task.bat to uninstall SigmaLink as scheduled task.
Server will be started at the login of any user on the computer.

2.7.6 Backup
No automatic backup system is provided by SigmaLink.
To save your data save C:\VIT_SigmaLink\data
To save the whole installation, stop the server then zip C:\VIT_SigmaLink.
2.7.7 Moving installation
If you want to change server or installation path, follow this process:
Stop your server
Install a new server (on a new machine or in a new path) using standard installation wizard
Copy the directory data/ of your old installation into the new one.
Delete old installation directory.
e.g. if your previous installation was in c:\VIT_SigmaLink\SigmaLink and you want to install into
d:\VIT_SigmaLink, copy the directory c:\VIT_SigmaLink\SigmaLink\data into d:\VIT_SigmaLink. At
the end, you must have a directory d:\VIT_SigmaLink\data and you mustn’t have
d:\VIT_SigmaLink\data\data.
