Vieweb.

- smtpServer
- bachEmailFrom
- batchReportDirectory

Ensure the Vieweb 1.5 server is stopped. http://localhost:8080/VIEWEB must display an error
“Page not found”. If necessary close the DOS Window called “Tomcat”.

4. Trouble shooting
4.1 Rollback to Vieweb 1.5
If you want to reinstall Vieweb 1.5 after an upgrade, use the vieweb 1.5 installer and use the
installation mode “Repair”. Follow all the steps and accept all installations.
4.2 Bad java version
ERROR
If when you launch the start_server.bat you have:
Can't start server : bad java version (found XXX/ require 1.7)
Please set properly the environment variable JAVA_HOME then restart the server
Or
Can't start server : java runtime environment not found
Please set properly the environment variable JAVA_HOME then restart the server
EXPLANATION
The startup script try to find a Java Virtual Machine and fail to find.
SOLUTION 1
This message can appear if you don’t have installed the Java provided with Vieweb.
Ensure the directory C:\Program Files (x86)\Java\jdk1.7.0_40 or C:\Program Files\Java\jdk1.7.0_40
exists (directory name for Program Files is depending of the OS language).
If not, follow (cf. Java Installation), then restart server (cf. Starting server).
SOLUTION 2
A message appear if Java is already installed on the machine. The installation can be cancelled in this
case. But you’ll have to follow the configuration step of the JAVA_HOME.

In this case, ensure Java is at least a java 1.7 version using the command line:
C:\java -version
java version "1.7.0_XXX"

Java HotSpot(TM) xx-bits Server VM (build XX.X-bXX, mixed mode)
The message can be quite different, but the version must be 1.7.

Update the line 16 : SET JAVA_DIR=%PRG_FILES_32%\Java\jdk1.7.0_40 by defining the real
installation path of your JDK.
e.g. SET JAVA_DIR=c :\jdk1.7.0_41
If you change the Java Version, many problems can occur. Be sure to understand what you’re
doing.

4.3 I can login, but I’ve a blank screen after
ERROR
Vieweb is started, you can login but when you click on the login button, a blank screen is displayed.
You can check the log file c:\VIT_Vieweb\logs\vieweb\Vieweb.log if message “Could not obtain
connection”.
EXPLANATION
Vieweb fail to connect to its internal database MySQL.
SOLUTION 1
Check if the service MySQL is started.
Control panel > Adminsitration tools > Services
Check that the service called MySQL is started.
If not, start the service, then stop and start the Vieweb server (cf. Starting server).
SOLUTION 2
Check if the database is always available.
In command line, go to bin directory of MySQL.
cd C:\Program Files\MySQL\MySQL Server 4.1\bin (*)
mysql -u root -proot
show databases;
(*) can be different according to the OS language and the OS architecture.
if the obtaining list doesn’t contains the name vieweb, your database have been dropped. Contact
the support and send the Vieweb.log file.

5. Annex
Important notes concerning advanced browser configuration:
1. Check that in "internet Options", "Connections", "LAN setting" tab, "automatically detect setting"
must be checked not "use a proxy server for your LAN...". You can also try to add Vieweb server
IP address in "exception" under "advanced" menu.
2. In Explorer "options tools", "advanced" tab, "Security" section, tick the parameter "allow
active content to run in files on My Computer".
3. Client browser configuration
VieWeb application works with popup and dynamics html pages. The client browser has to allow
theses popups in order to let the application working fine.
4. Internet explorer configuration
VieWeb is working with internet explorer version 6 and more. The browser has to be set as
follow:
(cid:2) Allow the popup with Internet explorer
(cid:2) Select the menu Utils/Options internet and select the Security tab.
o Click on the button Custom Level ...
o Deactivate the blocker of inopportune advertising windows (if available)
o Activate scripting
(cid:2) Internet settings are now OK.
5. Firefox configuration
Allow the popup with Firefox by:
(cid:2) Selecting the menu Tools/Options and select the Web Features tab
(cid:2) If popups are blocked, click on Allowed Sites button to allow them for the VieWeb serveur.
(cid:2) Add the server ip and click on Allow button.
6. Image resizing
(cid:2) Selecting the menu Tools/Options and select the Advanced tab and deselect the option
Resize large
images to fit in the browser window. Then, click OK
(cid:2) Firefox settings are now OK.
