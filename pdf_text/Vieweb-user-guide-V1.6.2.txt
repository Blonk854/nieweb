1.2 VieWeb functions
VieWeb aims at performing reporting on data recorded on the VIT AOI systems. The reporting can be
either on line (Real Time View) or as predefined reports (Reports List).
With the Real Time View, you can quickly build single entity that will not be saved. An entity, such as
defined in the VieWeb application, represents a specific functional analysis. Available entities are
displayed as tables (FPY, DPMO, traceability, process capability, measurement system analysis, test
empty master) or charts (error, deviation and trend).
With Reports List, you can build multi-entity reports and save them on the server to be reused later for
analysis on other period of time.
All functions of the application are described in this manual.
3 user profiles are available in the application:
(cid:132) Readers can perform online analysis and use pre-defined reporting.
(cid:132) Authors can create reports and configure several parameters.
(cid:132) Administrators have full access to the application and in particular are responsible for the applica-
tion configuration.
The accessibility of the functions depends on the user profile: admin / author / reader.
Reader rights are included in author rights; author rights are included in admin rights.
The restriction of the function to Author (°) or Admin (*) is specified when necessary.

3.1.2 Entity configuration: filters mechanism
Filters can be used to restrict the scope of the analysis. The selection of filters modifies the result
of the report to the selected criteria, for example a machine or particular defect.
Use filters when you need to explore more in details a situation and do not forget to remove them
if it is a temporary search.
You can combine multiple filters to add multiple conditions to the search (e.g. a board ID and a
P&P machine. Your request will thus bring back some computed data of components included
in this board and inspected by this P&P machine).
Combining multiple filters can alter the report response time.
Beware that all operators are not available for all filters as some fields can be used with complex
operators (e.g. ID codes can be used with a between operator) but not all of them.
Like operator means that the element to look for contains the criteria entered.
Example: ID code LIKE ‘0508’
In operator asks for a list of values between brackets to look for elements of that list.
Example: ID code IN (12, 13, 14)
Some filters offer to choose values among a list of values. For example if you choose to filter
on Board ID code and you select any operator different from like or not like, you get the follow-
ing interface:
1. Click on the Add button
2. Choose one or several values depending on the chosen operator.
3. Click on the next arrows if needed.
4. When finished, click on Save button or Cancel button to go back
to the filter definition screen.
5. Click on Save button or Cancel button to go back to the entity
screen

Glossary
AOI: Automatic Optical Inspection refers to any VIT equipment that performs PCB inspection.
AOI efficiency: % of AOI use in production on the selected period of time.
Board: Panel sub element;
Cp: Capability. Cp = IT / 6σ. IT parameters are defined in the configuration of the application. See Chapter 2
Application parameters for more details.
Cpk: Cpk = Min { IT/2 – Avg(deviations) / 3σ ; IT/2 + Avg(deviations) / 3σ }. IT parameters are defined in the
configuration of the application. See Chapter 2 Application parameters for more details.
DPMO: Default Per Million Opportunities. DPMO = (Number of defects * 1 000 000) / (total number of tests).
EV: Equipment Variation. Confidence coefficient parameter can be modified in the configuration of the appli-
cation. EV = Confidence coefficient * σ. See Chapter 2 MSA Limits for more details.
%EV: Tolerance EV parameter can be modified in the configuration of the application. %EV = EV * 100 / Tol-
erance EV. See Chapter 2 MSA Limits for more details.
FPY: First Pass Yield. FPY = (Number of panels (or boards)) / (Number of inspected panels (or boards)) * 100.
3 types of FPY:
- FPY AOI: FPY including all defects found by the AOI. Reflect the AOI performance.
- FPY diagnostic: FPY that does not include dummy faults that have been categorized by the repair operator.
Reflect the real product quality.
- FPY after repair: FPY including repaired defects. Reflect the product quality after reparation: informs on de-
fects that needs to be repaired.
IT: Interval of Tolerances. IT parameters are defined in the configuration of the application. See Chapter 2 Ap-
plication parameters for more details.
MSA: Measurement System Analysis.
Panel: A panel is a group of boards that are inspected at 1 time by the AOI.
GR&R: Gage Repeatability and Reproducibility. GR&R = 4.33 * Mean of differences * 100 / IT. Mean of differ-
ences shall be calculated following the example detailed below. Given a list of 9 elements. Only 8 will be taken
into account and listed as shown below:
First list Second list Difference
Delta_X 1 Delta_X 5 Abs(Delta_X 5 - Delta_X 1)
Delta_X 2 Delta_X 6 Abs(Delta_X 6 - Delta_X 2)
Delta_X 3 Delta_X 7 Abs(Delta_X 7 - Delta_X 3)
Delta_X 4 Delta_X 8 Abs(Delta_X 8 - Delta_X 4)
Mean of differences
PPM: Part Per Million. PPM = (Number of defects) / (Number of components + pads)* 1 000 000.
P&P: Pick & Place equipment = placement machine.
Shift: Work group, used as entities analysis parameters.
